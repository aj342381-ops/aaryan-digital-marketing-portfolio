## 🚀 Technology Stack

- **Framework**: React 18 with TypeScript
- **Bundler & Dev Server**: Vite 6
- **Styling**: Tailwind CSS 3 with custom color tokens:
  - Deep Navy Blue (`#0B1F3A`)
  - Professional Blue (`#2563EB`)
  - Clean Backgrounds (`#FFFFFF`, `#F4F7FC`)
  - Dark Charcoal Typography (`#172033`)
- **Icons**: Lucide React
- **Design Intelligence**: Built with Antigravity `ui-ux-pro-max` design system guidelines

## 💻 Local Development & Commands

### Prerequisites
- Node.js (v18+) & NPM

### Run Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### Build Production Bundle
```bash
npm run build
```
Creates an optimized, minified production build in the `dist/` directory.

### Preview Production Build
```bash
npm run preview
```

## 🌐 Easy Deployment Options

### Deploy to Vercel
1. Push this repository to GitHub.
2. Import the repository in [vercel.com](https://vercel.com).
3. Framework Preset: **Vite**.
4. Click **Deploy**.

### Deploy to Netlify
1. Drag and drop the `dist/` folder into [app.netlify.com/drop](https://app.netlify.com/drop) or connect to your GitHub repository.
2. Build command: `npm run build`
3. Publish directory: `dist`
